TOIRE Level Meter 1.0.1 — 安装前请阅读
========================================

这是什么
--------
TOIRE Level Meter 是一个 VST3 格式的音频电平表插件，用于在 DAW 中查看
峰值（PEAK）、有效值（RMS）及其保持值（HOLD）。

界面由嵌入式 WebView2 渲染。


安装前请先关闭 DAW
------------------
安装程序会覆盖插件文件。如果 Cubase、Studio One、Reaper、FL Studio、
Ableton Live 等宿主正在运行，文件会被占用，可能导致安装失败或插件异常。

请先完全退出这些程序，再继续安装。


插件会被装到哪里
----------------
    C:\Program Files\Common Files\VST3\TOIRE Level Meter.vst3

这是 VST3 规范约定的共享目录，绝大多数 DAW 会自动扫描。
安装完成后重新打开 DAW 即可在插件列表中找到它。

安装程序会需要管理员权限，因为该目录属于系统共享目录。


关于 Microsoft WebView2 运行时
------------------------------
插件界面依赖 Microsoft Edge WebView2 运行时。

- Windows 11 已内置，无需处理。
- Windows 10 如果没有装过，安装程序会自动为你安装（需要联网，约几十秒）。

这一步是自动的，你无需手动操作。如果安装时没有网络，插件装上后打开界面
会是空白，此时手动安装一次运行时即可恢复正常：

    https://developer.microsoft.com/microsoft-edge/webview2/


卸载
----
通过「设置 → 应用 → 已安装的应用」中的 “TOIRE Level Meter” 即可卸载。
卸载会移除整个插件目录，不会在共享的 VST3 目录里留下残留文件。


关于 Windows 安全提示
---------------------
本安装包未购买代码签名证书，因此首次运行 Windows SmartScreen 可能提示
「Windows 已保护你的电脑」。

如需继续，点击「更多信息」→「仍要运行」。

这是未签名程序的正常提示，不代表文件有问题。安装包的来源请以你收到它的
渠道为准。
